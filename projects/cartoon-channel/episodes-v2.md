Channel: **Oops! Toons** · Written by John (storyteller), 28 Oct 2026 · Status: **draft for Frank's approval** (nothing generated, nothing posted).

Replaces the 45 s, 7-shot versions in `episodes-01-07.md` (kept for reference). Rules come from `viral-fix.md`; looks come from `character-bible.md`. EP01 is the EP01 v2 from `viral-fix.md`, copied exactly.

## How to use

- **Ingredients for every shot:** `Moto_sheet_v1.png`, `Mishti_sheet_v1.png` (when she is in the shot) and the episode's location plate: `loc-lane.png`, `loc-rooftop.png`, `loc-home.png` or `loc-home-doorstep-rain.png`. The reference images carry the look, so the prompts stay short.
- **In Google Flow:** choose **Ingredients to Video**, set the aspect ratio to **9:16**, paste one grey box per clip, attach the ingredients.
- **Format:** 15–20 s, exactly 4 shots: **A HOOK** (something is already going wrong in frame 1), **B TRY** (Moto's clumsy fix makes it worse), **C TWIST** (Mishti's clever fix), **D PAYOFF + LOOP** (ends on the same problem as shot A, so the Short replays).
- **Each clip is ~8 s; the edit uses ~3–5 s of it.** Cut early. The edit times on each shot are where it sits in the finished Short.
- **If Veo ignores the action:** make the first frame as an image first (with the character sheet and location plate, in the exact pose: e.g. the scoop already in the air), then use that image as the **start frame** and animate it with the same prompt.
- **Check before keeping a clip:** the gag happens in the first second, props stay in a paw (nothing floats), nobody is hurt, no people, no text.
- **Sound:** Veo's sound is a guide track. Rebuild the key hits from a licensed SFX library in Premiere; light bouncy music bed under them, no vocals.

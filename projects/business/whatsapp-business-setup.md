**Verification note (21 Oct 2026):** WhatsApp's official Help Center (faq.whatsapp.com) could not be reached from

## 1. Install and register (10 min)

1. Install **WhatsApp Business** (free, green "B" icon) from Play Store / App Store.
2. Decide the number. Default picked: **use a separate business SIM** if Frank has one, so personal chats stay
   personal. If he moves his current number, the app can carry chat history over; back up WhatsApp first
   (Settings → Chats → Chat backup) before switching.
3. Business name: the same name as the Facebook page, so clients recognise it.
4. Category: **Photographer / Videographer** if listed, otherwise "Arts & entertainment" or "Other business"
   **(exact category list unverified)**.

## 2. Business profile fields

Settings → Business tools → **Business profile**. Fill every field; empty profiles look less trustworthy.

| Field | What to put |
|---|---|
| Profile photo | Clean logo or a well-lit portrait of Frank with the camera. Same as the Facebook page. |
| Business name | Same as the Facebook page name. |
| Category | Videographer / Photographer (see above). |
| Description | `Wedding, holud & engagement films · Restaurant/café Reels · Product videos. Solo filmmaker in Dhaka. Message for packages & dates.` |
| Address | Area only (e.g. "Dhaka, Bangladesh"). No home address. Leave the map pin off. |
| Business hours | "Open for selected hours", e.g. Sat–Thu 10:00–21:00, Fri closed. Adjust to real hours. |
| Email | Business email if Frank has one. |
| Website / links | Facebook page link (https://www.facebook.com/share/1XdgP8j57k/) and, later, Instagram/YouTube. |

## 4. Labels = tracker statuses

Labels are private (clients never see them) and colour-coded. On Android: long-press a chat → label icon. On
iPhone: swipe or open the chat → contact info → Add label **(exact gesture varies by version; unverified)**.
The app ships with default labels (New customer, New order, Pending payment, Paid, Order complete; **unverified**). Rename or
delete them and create these six so the chat list matches `lead-tracker.csv` exactly:

| Label | Use when | Suggested colour |
|---|---|---|
| New | They messaged first, or found but not yet messaged | Grey |
| Messaged | Frank sent the first personal message, no reply yet | Blue |
| Replied | They answered; conversation is live | Yellow |
| Quoted | Quote sent (Matthew's template) | Orange |
| Booked | Written confirmation **and** deposit received | Green |
| Lost | Said no, or no reply after one follow-up (then stop) | Red |

A chat has one status label at a time: remove the old one when moving it on. Label limit: third-party sources
say about 20 custom labels **(unverified)**; six is well within any limit. Note: newer WhatsApp versions also have
chat **Lists/filters**; labels are the Business-app feature we rely on here. If Frank's app shows labels as lists,
use the same six names.

## 5. Quick replies

Settings → Business tools → **Quick replies** → add. Each has a shortcut starting with `/`; in a chat type `/` and
pick one. They are never sent automatically, so Frank always edits before sending: add the person's name and one
real detail. Sources say up to 50 quick replies **(limit unverified)**. Keep shortcuts exactly as below.

**/price**
> Assalamu alaikum! Thanks for asking My packages:
> A) Wedding/Holud/Engagement film – from [price] BDT
> B) Café/Restaurant Reels (3 Reels) – [price] BDT
> C) Product video starter – [price] BDT
> Apnar date, location ar event/product ta bolle exact quote pathiye dibo within 24 hours.

**/sample**
> Ei holo amar recent kaj: [link]. Wedding/holud er jonno [link], café Reels er jonno [link].
> Apnar kon type ta lagbe janale similar aro sample share korbo.

**/booking**
> Date lock korte [deposit %] advance lagbe (bKash or bank transfer), baki ta delivery te.
> bKash: [number] · Bank: [details]. Payment er screenshot pathale written confirmation diye dibo. Thank you!

**/thanks**
> Thank you so much for choosing me! Kaj ta kemon laglo janaben. Jodi bhalo lage, Facebook page e ekta
> recommendation dile onek help hobe: [page link]. Kono friend er video lagle amake refer korte paren.

(Fill `[deposit %]` from Matthew, default 50%.)

## 6. Greeting and away messages

**Greeting message** — Settings → Business tools → **Greeting message** → turn on. Sent automatically the first
time someone messages, and again after a long gap (third-party sources say 14 days of no messages; **unverified**).
Recipients: "Everyone" (or exclude saved personal contacts if using his own number).

> Assalamu alaikum, thanks for messaging! I'm Frank, a filmmaker in Dhaka. Please share:
> 1) Event/product type 2) Date 3) Location 4) Budget range (approx.)
> Ami kichukkhon er moddhe reply dibo.

**Away message** — Settings → Business tools → **Away message** → turn on. Schedule: **Outside of business hours**
(uses the hours from the profile). Use "Custom schedule" on shoot days, and "Always send" only when fully away.

> Thanks for your message! Ekhon shoot/editing e achi. Kal sokal [time] er moddhe reply dibo.
> Urgent hole date ar location ta likhe rakhun, ami first e oita dekhbo.

Both are automatic first replies, not mass messaging, so they fit the plan's ethics. Do **not** use broadcast
lists for cold outreach; every outreach message is personal and sent by Frank.

## 7. 10-minute daily routine (part of the plan's daily 15 min)

Do it once a day, same time (default: 21:00, after replies are done). Open WhatsApp, Messenger and
`lead-tracker.csv` (or the Google Sheet copy) side by side.

| Min | Step |
|---|---|
| 0–2 | **New chats:** any unlabelled chat on WhatsApp or Messenger → label `New` (or `Replied`) and add a tracker row: lead, business, niche, area, source link, first contacted date. |
| 2–5 | **Status changes:** for every chat that moved today, change the label and the tracker `status` to match. Update `last message` to today. |
| 5–7 | **Follow-ups:** sort the tracker by `follow-up due`. Anyone due today and still `Messaged` → one polite follow-up (only one, per the plan). No reply after that → `Lost`, and stop. Set the next `follow-up due` for everyone else (default: 5–7 days after last message). |
| 7–9 | **Money:** quote sent → `Quoted` + amount in `quote BDT`. Deposit screenshot received and checked in bKash/bank → `deposit received` = Yes, status `Booked`, and tell Peter for the job plan. |
| 9–10 | **Notes + backup:** one line in `notes` (what they want, the detail to mention next time). Weekly on Sunday: download a copy of the sheet (File → Download → CSV) into the backed-up business folder. |

Tips: keep date columns as `YYYY-MM-DD` so sorting works. Delete the two `EXAMPLE – delete` rows before adding
real leads. Messenger has no WhatsApp-style labels in the tracker sense, so the tracker is the single source
of truth for Messenger leads.
